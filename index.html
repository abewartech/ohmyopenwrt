Tutorial Gratis

Mulai dari sini kalau kamu baru kenal OpenWRT.

1. Apa itu OpenWRT & kenapa pakai

OpenWRT adalah firmware pengganti berbasis Linux untuk router. Firmware bawaan router biasanya dikunci fiturnya dan jarang diupdate; OpenWRT membuka semuanya: QoS, VPN, adblock level router, VLAN, hotspot voucher, sampai monitoring trafik — semua dari satu dashboard web (LuCI).

Kenapa worth it? Kontrol penuh, keamanan lewat update rutin, dan performa.

  1. Cek dukungan router di Table of Hardware.
  2. Unduh firmware sesuai model dan revisi hardware persis.
  3. Siapkan kabel LAN, jangan flashing via WiFi.

2. Cara install OpenWRT di router

Instalasi umumnya lewat halaman update firmware bawaan router: upload file BIN OpenWRT, tunggu 3-5 menit, router reboot sendiri.

Risiko brick: flashing yang salah bisa membuat router tidak bisa boot. Unduh firmware untuk model yang tepat dan jangan cabut kabel saat proses berjalan.

  1. Backup konfigurasi firmware bawaan.
  2. Hubungkan PC ke router via kabel LAN.
  3. Upload firmware OpenWRT lewat menu update, tunggu reboot.
  4. Akses 192.168.1.1, selamat datang di LuCI.

3. Konfigurasi dasar setelah install

Langkah pertama: amankan router. Ganti password root, atur koneksi WAN sesuai ISP (DHCP/PPPoE/statik), lalu nyalakan WiFi dengan enkripsi WPA2/WPA3.

  1. Login ke 192.168.1.1, buka System Administration, set password root yang kuat.
  2. Buka Network Interfaces, edit WAN sesuai tipe koneksi ISP-mu.
  3. Buka Network Wireless, enable radio, isi SSID dan password WiFi.
  4. Simpan dan Apply, lalu tes koneksi dari HP/laptop.

4. Pasang AdBlock dan SQM/QoS

AdBlock memblokir iklan di level router. SQM menjaga latency tetap rendah saat bandwidth penuh, musuh utama lag saat main game atau video call.

  1. Buka System Software, update lists, install luci-app-adblock dan luci-app-sqm.
  2. Aktifkan AdBlock di Services AdBlock, enable dan start.
  3. Buka Network SQM QoS: centang Enable, isi kecepatan 90-95 persen dari kecepatan riil, pilih cake.
  4. Tes speedtest sambil ping, latency harus stabil meski bandwidth penuh.

5. Backup dan restore konfigurasi

Sebelum oprek lebih jauh, selalu backup. Satu file arsip berisi seluruh konfigurasi, restore dalam semenit kalau ada yang salah.

  1. Buka System Backup Flash Firmware.
  2. Klik Generate archive, simpan file arsip di tempat aman.
  3. Untuk restore: upload arsip di halaman yang sama, lalu reboot.
